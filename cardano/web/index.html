Pay-on-Proof on Cardano

Money moves only when signed real-world data proves a condition agreed in advance. One Aiken validator checks an AirnodeHub response itself: who signed it, which request it answers, how old it is, and whether it meets the rule.

Tamper bench

Pick a policy, paste or edit a signed response, and send it to the contract. The answer is the validator's own script evaluation on the Cardano preprod node provider. Nothing is ever sent to the chain from this page.

Change a value, the timestamp, the request hash or the signature, then send it. Load an example with the buttons.

Hire the keeper (x402 on Cardano)

A keeper agent that does one job: for a locked policy it fetches a fresh signed response and, if the rule holds, releases the funds to the policy's beneficiary. You pay 2 tADA by x402 per request, and only when it releases. If the rule is not met, or anything fails, the payment is cancelled.

npx tsx src/keep-client.ts --ref <txHash>#<index>

The service wallet pays the release fee and never holds the policy's funds. The response includes the signed evidence, which can be pasted into the bench above.

What this does not prove

A signature proves what the API returned, not that it is true. The contract does not check the data's own observation time, only when the Airnode signed. The rule is a sum of numeric slots compared with a threshold. Not audited; test funds only.
