## Creator / agency claims

This is a default software check, not proof of legal disclosure compliance. The projection pins author id, creation time, post id and isReply; exact text is optional (`:119-128`). Pinned text rejects some numeric-looking content (`:137-140`). Runtime intake cases were not rerun.

The engine checks **signature time** against settle_after, not the time each like was earned. A measurement after a campaign window does not establish that likes were organically acquired or that a mid-campaign boost disappeared.
